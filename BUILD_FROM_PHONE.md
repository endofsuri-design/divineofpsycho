# Build the APK from a phone

1. Create/sign in to a GitHub account.
2. Create a new repository and upload the contents of this project.
3. Open the repository's **Actions** tab.
4. Select **Build Android APK** and press **Run workflow**.
5. When it finishes, open the workflow run and download the `suri-esports-debug-apk` artifact.

The APK produced here is a debug build. Real payment credentials must be configured only on the server/merchant account; never put secret keys in the Android app.
